# PMM Dump 0.8.1-ga

* **Date**

    May 8, 2026

* **Installation**

    [Installing PMM Dump](../installation.md)

## Release Highlights

* This is the fourth General Availability release of PMM Dump. This release addresses multiple important security vulnerabilities affecting `libarchive` (CVE-2026-4424, CVE-2026-4111), `libnghttp2` (CVE-2026-27135), `gnupg2` (CVE-2025-68973), and `openssl-libs` (CVE-2025-15467).

## Bugs Fixed

* [SE-121](https://jira.percona.com/browse/SE-121) Failed tests: TestDashboard,TestQANEmptyChunks starting from PMM 3.5.0
